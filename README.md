# LinkedIn AI Prompt Framework

A simple, personal collection of tuned system prompts built to fix a common problem: AI-generated LinkedIn posts sound robotic, generic, and unengaging.

## What This Project Does
Instead of relying on basic ChatGPT prompts that output corporate buzzwords, this repository holds specific rules and constraints to make LLM output sound natural and conversational.

## Core Files
- **`skills/humanizer.md`**: Strips out overused AI buzzwords, forced corporate jargon, and unnatural formatting.
- **`skills/post-writer.md`**: Takes rough ideas or bullet points and structures them into readable posts with strong opening hooks.
- **`skills/content-planner.md`**: Organizes post topics into a structured weekly content table.

## Local Setup
I test and run these prompt files locally on my laptop using **LM Studio / Ollama** (Llama 3 8B model). This keeps the process fast, private, and completely free without needing API keys.
